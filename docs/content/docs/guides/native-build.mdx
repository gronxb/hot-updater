## Command Status

`build:android` is available by default. The other native helpers are
experimental and appear only when `EXPERIMENTAL=1` is set.

| Command         | Status       | Result                                                                                |
| --------------- | ------------ | ------------------------------------------------------------------------------------- |
| `build:android` | Available    | Builds an APK/AAB and copies the build directory to the artifact output path.         |
| `build:ios`     | Experimental | Builds an archive/app/IPA and copies the build directory to the artifact output path. |
| `run:android`   | Experimental | Builds, installs, and launches the app on an Android device or emulator.              |
| `run:ios`       | Experimental | Builds, installs, and launches the app on an Apple device or simulator.               |

The `run:*` commands act directly on a target. They do not run build-plugin
native hooks or copy artifacts to `.hot-updater/output`.

## Prerequisites

- A React Native project with the platform directory you plan to build.
- The local platform toolchain: Gradle/Android SDK or Xcode, CocoaPods, and
  `devicectl`/`simctl`.
- At least one named scheme under `nativeBuild.android` or
  `nativeBuild.ios`.
- A configured `updateStrategy`. Native builds refresh fingerprint metadata
  for the fingerprint strategy and read the native app version for
  `appVersion`.

Set the default channel before a store build:

```package-install
npx hot-updater channel set production
```

On Android, the command writes application-level metadata in
`AndroidManifest.xml`:

```xml title="android/app/src/main/AndroidManifest.xml"
<application ...>
  <meta-data
    android:name="com.hotupdater.CHANNEL"
    android:value="production" />
</application>
```

Hot Updater discovers Android manifests automatically. For non-standard
projects or multiple variants, configure them explicitly:

```ts title="hot-updater.config.ts"
platform: {
  android: {
    androidManifestPaths: [
      "android/app/src/main/AndroidManifest.xml",
      "android/app/src/internal/AndroidManifest.xml",
    ],
  },
},
```

`stringResourcePaths` and the old `strings.xml` keys remain available only
as a deprecated read fallback for older projects.

## Configure Native Build Schemes

```ts title="hot-updater.config.ts"
import { defineConfig } from "hot-updater";

export default defineConfig({
  // ... build, storage, database, and updateStrategy
  nativeBuild: {
    android: {
      releaseApk: {
        packageName: "com.example.app",
        variant: "Release",
        aab: false,
      },
      internalAab: {
        packageName: "com.example.app",
        applicationId: "com.example.app.internal",
        variant: "InternalRelease",
        appModuleName: "app",
        aab: true,
      },
    },
    ios: {
      release: {
        bundleIdentifier: "com.example.app",
        scheme: "ExampleApp",
        configuration: "Release",
        exportOptionsPlist: "./ios/ExampleApp/ExportOptions.plist",
        installPods: true,
      },
      simulatorDebug: {
        bundleIdentifier: "com.example.app.dev",
        scheme: "ExampleApp",
        configuration: "Debug",
        simulator: true,
      },
    },
  },
});
```

### Android Scheme Options

| Field           | Description                                        | Default       |
| --------------- | -------------------------------------------------- | ------------- |
| `packageName`   | Android package name.                              | Required      |
| `variant`       | Gradle build variant.                              | `Release`     |
| `aab`           | Build `.aab` when `true`, otherwise `.apk`.        | `true`        |
| `appModuleName` | Android application module.                        | `app`         |
| `applicationId` | Application ID used to install and launch the app. | `packageName` |

### iOS Scheme Options

| Field                | Description                                                                                | Default                    |
| -------------------- | ------------------------------------------------------------------------------------------ | -------------------------- |
| `bundleIdentifier`   | App bundle identifier.                                                                     | Required                   |
| `scheme`             | Xcode scheme.                                                                              | Required                   |
| `platform`           | Apple platform.                                                                            | `ios`                      |
| `configuration`      | Xcode build configuration.                                                                 | `Release`                  |
| `destination`        | Destination IDs, names, `ios-device`, or `ios-simulator`.                                  | `["generic/platform=iOS"]` |
| `simulator`          | Convenience shortcut for a `build:ios` simulator build; do not combine with `destination`. | `false`                    |
| `exportOptionsPlist` | Plist used to export an archive.                                                           | `undefined`                |
| `xcconfig`           | Additional Xcode configuration file.                                                       | `undefined`                |
| `installPods`        | Install CocoaPods dependencies before building.                                            | `false`                    |
| `extraParams`        | Extra `xcodebuild` parameters.                                                             | `[]`                       |
| `exportExtraParams`  | Extra `-exportArchive` parameters.                                                         | `[]`                       |

## Build Artifacts

A scheme is required unless you use interactive mode.

```package-install
npx hot-updater build:android -s releaseApk
EXPERIMENTAL=1 npx hot-updater build:ios -s release
```

Build commands support:

```txt
-s, --scheme <scheme>           use a configured native-build scheme
-o, --output-path <outputPath>  copy the completed build directory here
-i, --interactive               select a scheme interactively
```

The default output is
`.hot-updater/output/build/<platform>/<scheme>`. Hot Updater recreates that
directory for each build, so copy an artifact elsewhere if it must persist
across builds.

Only `build:*` runs the selected build plugin's `nativeBuild.prebuild` and
`nativeBuild.postbuild` hooks, then copies the completed build directory.
For iOS, `exportOptionsPlist` controls whether the archive is exported as an
IPA.

## Run on a Device or Simulator

Both run commands are experimental:

```package-install
EXPERIMENTAL=1 npx hot-updater run:android -s releaseApk -d emulator-5554
EXPERIMENTAL=1 npx hot-updater run:ios -s simulatorDebug -d "iPhone 16 Pro"
```

`run:android` accepts an ADB device ID or known emulator name. It also supports
`--port <port>` for ADB reverse and `--app-id-suffix <suffix>`.

`run:ios` accepts an available Apple device or simulator name, formatted name,
or identifier. In interactive mode, `-d` lets you choose from discovered
targets. Without a selected target, the command chooses an available target.

The `run:*` flow prepares native metadata, builds the app, installs it, and
launches it directly. Options such as `outputPath`, artifact copying, and
build-plugin native hooks apply only to `build:*`.
