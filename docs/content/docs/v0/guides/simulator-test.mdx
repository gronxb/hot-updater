## Checklist

- Configure `hot-updater.config.ts`.
- Set up `HotUpdater.wrap`.

## Step 1: Simulator Release Mode

Run your app in Release mode to test hot-updater (it doesn't work in dev mode).

<Tabs items={['Bare (React Native CLI)', 'Rock', 'Expo']}>
  <Tab value="Bare (React Native CLI)">
    **iOS:**
    ```sh
    cd ios && pod install && cd ..
    npx react-native run-ios --mode Release
    ```

    **Android:**
    ```sh
    npx react-native run-android --mode Release
    ```

  </Tab>
  <Tab value="Rock">
    **iOS:**
    ```sh
    npx rock run:ios --configuration Release
    ```

    **Android:**
    ```sh
    npx rock run:android --variant Release
    ```

  </Tab>
  <Tab value="Expo">
    **iOS:**
    ```sh
    npx expo run:ios --configuration Release
    ```

    **Android:**
    ```sh
    npx expo run:android --variant release
    ```

  </Tab>
</Tabs>

## Step 2: Deploy

To test an immediate update, deploy in interactive mode with the force update flag enabled.

When [HotUpdater.wrap](/docs/v0/react-native-api/wrap) is set up, updates will be applied when you restart the app.

You can check the update progress status using [useHotUpdaterStore](/docs/v0/react-native-api/useHotUpdaterStore).

<video src={"/docs/deploy/deploy.mov"} controls autoPlay loop muted />

### For Normal Deployment

In standard deployment mode, users must restart the app after downloading the bundle to apply the update.

```package-install
npx hot-updater deploy -i
```

### For Emergency Deployment

In emergency deployment mode, the app reloads and applies the update as soon as the bundle finishes downloading.

```package-install
npx hot-updater deploy -i --force-update
```

## Step 3: Rollback

<video src={"/docs/console/console.mp4"} controls autoPlay loop muted />

When you set a bundle's `enabled` status to `false` in the console, users who have that bundle will immediately force update to the **previous bundle**.

Open the console and set the bundle's `enabled` status to `false`.

```package-install
npx hot-updater console
```
