## Plugin Token Protection

`hot-updater.config.ts` is CLI configuration. It may contain credentials used
to upload artifacts or write database records, so load those values only in
local tooling and CI. Do not import this file from React Native application
code.

```ts title="hot-updater.config.ts"
import { bare } from "@hot-updater/bare";
import { supabaseDatabase, supabaseStorage } from "@hot-updater/supabase";
import { defineConfig } from "hot-updater";
import { config } from "dotenv";

config({ path: ".env.hotupdater" });

export default defineConfig({
  updateStrategy: "appVersion",
  build: bare({ enableHermes: true }),
  storage: supabaseStorage({
    supabaseUrl: process.env.HOT_UPDATER_SUPABASE_URL!,
    supabaseServiceRoleKey: process.env.HOT_UPDATER_SUPABASE_SERVICE_ROLE_KEY!,
    bucketName: process.env.HOT_UPDATER_SUPABASE_BUCKET_NAME!,
  }),
  database: supabaseDatabase({
    supabaseUrl: process.env.HOT_UPDATER_SUPABASE_URL!,
    supabaseServiceRoleKey: process.env.HOT_UPDATER_SUPABASE_SERVICE_ROLE_KEY!,
  }),
});
```

## What is included in the app

The Hot Updater CLI reads `hot-updater.config.ts`; the React Native bundler does
not include it automatically. Credentials remain out of the app as long as
application code does not import the config or inject the same environment
variables into the client bundle.

```ts
import { HotUpdater } from "@hot-updater/react-native";

export default HotUpdater.wrap({
  baseURL: "https://<your-update-server-url>",
  updateStrategy: "appVersion", // or "fingerprint",
});
```

The update server URL is public application configuration. Supabase service
role keys, Cloudflare API tokens, private signing keys, and other server
credentials must remain in local or server-side environments.

## Potential Token Exposure

<Callout type="warn">
  Environment-variable libraries replace referenced values in the client bundle.
  Only expose variables whose values are safe to publish.
</Callout>

### Example with `react-native-dotenv`

Allowlist only public client configuration:

```js title="babel.config.js"
module.exports = {
  presets: ["module:@react-native/babel-preset"],
  plugins: [
    [
      "module:react-native-dotenv",
      {
        envName: "APP_ENV",
        allowlist: [
          "HOT_UPDATER_SUPABASE_SERVICE_ROLE_KEY",
          "HOT_UPDATER_CLOUDFLARE_API_TOKEN",
        ], // [!code --]
        allowlist: ["HOT_UPDATER_SUPABASE_URL"], // [!code ++]
        path: ".env.hotupdater",
      },
    ],
  ],
};
```

## Best Practices

1. Keep service credentials and private signing keys in local tooling, CI, or
   the deployed server environment.
2. Allowlist only public values when an environment-variable library injects
   configuration into the mobile bundle.
3. Keep `.env.hotupdater` out of version control and scope each credential to
   the minimum provider permissions it needs.
4. Rotate or revoke a credential immediately if it is committed or included in
   a client build.
