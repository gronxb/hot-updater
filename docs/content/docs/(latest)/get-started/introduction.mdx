## What is Hot Updater?

Hot Updater delivers JavaScript and asset updates to React Native apps over the
air. You host the update infrastructure in your own account, using Cloudflare,
Supabase, AWS, Firebase or a custom server. Native code changes require a new
native app build.

These pages describe the latest stable v1 release.

## What a completed setup looks like

Both the agent and manual paths lead to the same verified result:

1. The app has compatible v1 SDK, CLI and plugins.
2. The deployed server has a known base URL and working client authentication.
3. A native Release build loads Hot Updater and uses the intended channel and
   compatibility target.
4. A JavaScript and asset change arrives through OTA and is visible after the
   app applies it.
5. You can inspect that update in the Console and verify its rollback behavior
   and [Insights](/docs/guides/insights) reports when reporting is enabled.

Server deployment, native launch and OTA application are separate checks. An
agent should report which passed and any remaining native release steps.
