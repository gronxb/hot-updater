## Usage

Use `HotUpdater.resetChannel()` to return to the bundle and channel embedded in
the installed app. The reset is not conditional on a runtime channel switch:
it also removes downloaded OTA state when the current channel is already the
build-time default.

```tsx
import { HotUpdater } from "@hot-updater/react-native";

async function handleResetChannel() {
  const didReset = await HotUpdater.resetChannel();
  if (didReset) {
    await HotUpdater.reload();
  }
}
```

## Behavior

- Clears any runtime channel override.
- Removes downloaded OTA bundle state and restores the built-in bundle
  selection.
- Makes the build-time default channel active immediately in the client state;
  reload to start executing the built-in bundle.
- Runs the same reset when `HotUpdater.isChannelSwitched()` is `false`, so do
  not use that value to infer that the call is a no-op.
- Resolves to `true` when the native reset succeeds and `false` otherwise.

## Example

```tsx
const didReset = await HotUpdater.resetChannel();
if (didReset) {
  await HotUpdater.reload();
}
```

## When to Use

- Leave a beta or staging runtime channel switch
- Add a "Return to default channel" action in a debug or settings screen
- Recover to the original shipped bundle after testing another channel
