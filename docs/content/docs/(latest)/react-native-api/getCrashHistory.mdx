## Usage

Use `HotUpdater.getCrashHistory()` in a support log or debug screen to inspect
artifacts that crashed and triggered automatic rollback.

```tsx
import { HotUpdater } from "@hot-updater/react-native";

const crashedArtifacts = HotUpdater.getCrashHistory();
console.log("Rejected artifact IDs:", crashedArtifacts);
```

## Return Value

```ts
getCrashHistory(): string[]
```

Each value matches the Console's Advanced **Artifact ID**. It is not the update
ID returned by [`getBundleId()`](/docs/react-native-api/getBundleId). An empty
array means the device has no recorded crashed artifacts.

The getter is synchronous and reads local history without making a network
request. Recorded artifacts are rejected if the device attempts to install
them again. [`clearCrashHistory()`](/docs/react-native-api/clearCrashHistory)
clears that rejection history for a controlled retry.

Crash detection and app-ready reporting are configured through either
[`wrap`](/docs/react-native-api/wrap) or [`init`](/docs/react-native-api/init).
Use one of them, and see [automatic rollback](/docs/concepts/automatic-rollback)
for the recovery lifecycle.
