## Usage

Use `HotUpdater.getInstallId()` to connect a support report to an installation
in [Insights](/docs/guides/insights).

```tsx
import { HotUpdater } from "@hot-updater/react-native";

const installId = HotUpdater.getInstallId();
console.log("Hot Updater installation:", installId);
```

## Return value

```ts
getInstallId(): string
```

The getter is synchronous and makes no network request. It returns a random ID
that native creates once per installation of the app. Native keeps it outside
device backups, so restoring a backup onto another device does not copy it.
The ID stays the same across launches and OTA updates; reinstalling the app
creates a new one.

This identifies an app installation, not a person. Multiple installations for
one user have separate IDs and count separately in Insights. The Insights
plugin's [`setUser`](/docs/react-native-api/insights#set-the-user), including
`setUser(null)`, does not change the installation ID. Client plugins read the
same ID as `context.installId`.

In the Console, open **Insights → All events** and search for this ID to inspect
received reports. An ID only appears there after the server receives a report
from the [Insights plugin](/docs/react-native-api/insights).
