## Usage

Use `HotUpdater.clearCrashHistory()` when testing a previously rejected
artifact again. Clearing history only changes the current device: it does not
deploy a Release, change delivery policy, download an update, or reload the app.

```tsx
import { HotUpdater } from "@hot-updater/react-native";

HotUpdater.clearCrashHistory();
const remainingArtifacts = HotUpdater.getCrashHistory();

if (remainingArtifacts.length === 0) {
  console.log("Device crash history is empty");
} else {
  console.error("Crash history still contains rejected artifacts", remainingArtifacts);
}
```

## Return value

```ts
clearCrashHistory(): boolean
```

On iOS, returns `true` when the cleared history is saved and `false` if saving
fails. On Android, returns `true` even if saving fails; the return value does not
confirm that the history was cleared. Read
[`getCrashHistory()`](/docs/react-native-api/getCrashHistory) afterward when you
need to confirm that no rejected artifacts remain.

The method is synchronous and does not make a network request.

An artifact that caused a crash can be selected again after clearing history.
Use this for a controlled retry after investigating the failure; calling it at
every startup removes the protection provided by the rejection history.
