---
title: "Artifact Compression"
description: "How Hot Updater compresses manifest assets."
icon: FileArchive
---

Hot Updater v1 distributes OTA updates as a manifest and individual files. It
does not create or download ZIP, `tar.gz`, or `tar.br` bundle archives.

Deploy automatically compresses eligible individual files with Brotli. The
manifest records the logical installed-file hash and, when the served bytes are
compressed, the download hash and byte size. Native clients decompress and
verify each file before staging the update.

There is no compression setting. Remove `compressStrategy` from
`hot-updater.config.ts`; v1 rejects the removed option so stale configuration
cannot silently change deployment behavior.

```bash
npx hot-updater deploy -p ios
npx hot-updater deploy -p android
```

Per-file compression lets the client skip files already present in the current
OTA or built-in app and download only the files it needs.
