## Installation

```package-install
npm install @hot-updater/server @hot-updater/supabase --save-dev
```

## Setup

For a complete provider deployment, follow the [Supabase setup](/docs/managed/supabase#step-2-configure-supabase).
For an existing bucket or a custom server, use the storage configuration below;
you do not need to provision the provider's database and server to use this plugin.

## Configuration

```typescript
interface SupabaseStorageConfig {
  supabaseUrl: string; // Your Supabase project URL
  supabaseServiceRoleKey: string; // Your Supabase service role or secret key
  bucketName: string; // Storage bucket name
  basePath?: string; // Optional base path within bucket
  signedUrlExpiresIn?: number; // Default: 3600 seconds
}
```

## Usage

Add the adapter to `storage` in your
[server definition](/docs/custom/quick-start#define-the-server), which `server`
in `hot-updater.config.ts` points at. The CLI uploads to the first adapter, and
the server resolves downloads with it:

```typescript title="hotUpdater.ts (excerpt)"
import { supabaseStorage } from "@hot-updater/supabase"; // [!code ++]
import { createHotUpdater } from "@hot-updater/server";

export const hotUpdater = createHotUpdater({
  // ... database and plugins
  storage: [ // [!code ++]
    supabaseStorage({ // [!code ++]
      supabaseUrl: process.env.SUPABASE_URL!, // [!code ++]
      supabaseServiceRoleKey: process.env.SUPABASE_SERVICE_ROLE_KEY!, // [!code ++]
      bucketName: "hot-updater-bundles", // [!code ++]
      basePath: "bundles", // Optional // [!code ++]
    }), // [!code ++]
  ], // [!code ++]
});
```

## Protocol

`supabase-storage://bucket/encoded/key`

For example,
`supabase-storage://updates/releases/1.0.0/bundle%20ios.zip` is stored in the
`storageUri` field. Keys retain their slash hierarchy and encode each segment.

## Capabilities

`supabaseStorage` passes the upload stream to Supabase, but downloads resolve to
a complete `Blob` before the plugin constructs its Web `Response`. It also
implements signed download URL generation, existence checks, and exact deletion.
For Supabase Edge Functions, import the same `supabaseStorage` name from
`@hot-updater/supabase/edge`; that implementation captures the edge-compatible
client configuration without changing the core contract.
