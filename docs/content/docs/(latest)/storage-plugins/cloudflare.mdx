## Installation

```package-install
npm install @hot-updater/cloudflare
```

## Setup

The easiest way to set up your backend is using the init command:

```package-install
npx hot-updater init
```

This interactive command will guide you through the setup process. For details on what the init command does, see the [Cloudflare](/docs/managed/cloudflare) documentation.

For manual configuration, use the settings below.

Create R2 S3-compatible credentials from the Cloudflare R2 API token page or
follow the [Cloudflare R2 API token guide](https://developers.cloudflare.com/r2/api/tokens/).

## Configuration

```typescript
interface R2S3StorageConfig {
  accountId: string;
  bucketName: string;
  credentials: {
    accessKeyId: string;
    secretAccessKey: string;
  };
  basePath?: string;
  downloadUrlSigningKey?: string;
}

interface R2WranglerStorageConfig {
  accountId: string;
  bucketName: string;
  cloudflareApiToken: string;
  basePath?: string;
  credentials?: never;
}
```

S3-compatible credentials enable the root runtime profile. The
`cloudflareApiToken` form remains the legacy Wrangler-based CLI configuration.

## Usage

```typescript
import { r2Storage } from "@hot-updater/cloudflare";
import { defineConfig } from "hot-updater";

export default defineConfig({
  storage: r2Storage({
    accountId: process.env.CLOUDFLARE_ACCOUNT_ID,
    bucketName: "my-r2-bucket",
    credentials: {
      accessKeyId: process.env.R2_ACCESS_KEY_ID,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
    },
  }),
  // ... other config
});
```

## Runtime Usage

With S3-compatible credentials, the root `r2Storage` plugin implements upload,
read, existence-check, and exact-delete operations. When the same plugin is
passed to a self-hosted `createHotUpdater` server, also provide
`downloadUrlSigningKey`; it enables the signed download location required by
the server while `get` reads the stored object.

The legacy `cloudflareApiToken` configuration runs object operations through
Wrangler. It is retained for existing CLI configurations, but it does not
provide the signed download operation required by `createHotUpdater`.

## Limitations

- Legacy `r2Storage` configs without `credentials` use Wrangler and are slower
  than the S3-compatible API path.

## Protocol

`r2://bucket/encoded/key`

For example, `r2://updates/releases/1.0.0/bundle%20ios.zip` is stored in the
`storageUri` field. Keys retain their slash hierarchy and encode each segment.
