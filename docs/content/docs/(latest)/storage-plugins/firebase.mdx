## Installation

```package-install
npm install @hot-updater/firebase firebase-admin dotenv --save-dev
```

For a deployed server, install these packages as runtime dependencies instead
of development dependencies.

## Setup

For a complete provider deployment, follow the [Firebase setup](/docs/managed/firebase#step-2-configure-firebase).
For an existing bucket or a custom server, use the storage configuration below;
you do not need to provision the provider's database and server to use this plugin.

## Configuration

```typescript
import type { Credential } from "firebase-admin/app";

interface FirebaseStorageConfig {
  projectId: string; // Firebase project ID
  storageBucket: string; // Storage bucket name
  credential: Credential; // Firebase credential
  basePath?: string; // Optional base path within bucket
  cdnUrl?: string; // Optional CDN URL
  signedUrlExpiresIn?: number; // Default: 3600 seconds
}
```

## Environment Variables

Use an existing application-default identity when available. Set
`GOOGLE_APPLICATION_CREDENTIALS` only when you need a private credential file;
keep the file outside the app bundle and exclude local environment files from
Git. A Firebase CLI login alone does not necessarily authenticate the local
Admin SDK.

```bash title=".env.hotupdater"
# Optional: a private credential file when existing ADC is unavailable
# GOOGLE_APPLICATION_CREDENTIALS=/private/path/to/your-service-account-key.json
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_STORAGE_BUCKET=your-bucket-name
```

## Usage

```typescript title="hot-updater.config.ts"
import { firebaseStorage } from "@hot-updater/firebase"; // [!code ++]
import { config } from "dotenv";
import { applicationDefault } from "firebase-admin/app";
import { defineConfig } from "hot-updater";

config({ path: ".env.hotupdater" });

// Reuse the environment's application-default credentials.
const credential = applicationDefault();

export default defineConfig({
  storage: firebaseStorage({ // [!code ++]
    projectId: process.env.FIREBASE_PROJECT_ID, // [!code ++]
    storageBucket: process.env.FIREBASE_STORAGE_BUCKET, // [!code ++]
    credential, // [!code ++]
  }), // [!code ++]
  // ... other config
});
```

## Protocol

`gs://bucket/encoded/key`

For example, `gs://my-bucket/releases/1.0.0/bundle%20ios.zip` is stored in the
`storageUri` field. Keys retain their slash hierarchy and encode each segment.

## Capabilities

`firebaseStorage` implements the Web-stream upload and `Response` read contract,
but the current Firebase Admin implementation buffers each complete upload and
download in memory. It also implements download URL generation, existence
checks, and exact deletion. `getDownloadUrl` returns a CDN URL when `cdnUrl` is
configured and a Firebase signed URL otherwise.
