## Prerequisites

- BugSnag Account: Sign up here if you don't have one.
- API Key: Copy the API key of your project from your BugSnag dashboard.
- Complete the [BugSnag React Native setup](https://docs.bugsnag.com/platforms/react-native/react-native/manual-setup/), including the `@bugsnag/react-native` runtime package, iOS pods, and native API-key configuration and initialization. Verify that your app reports a test error before adding OTA sourcemap uploads.
- Install the plugin:

```package-install
npm install @hot-updater/bugsnag-plugin @bugsnag/cli --save-dev
```

## Step 1: Wrap your build adapter

Use `withBugsnag()` to wrap any compatible build adapter such as bare.

<Tabs items={['Bare', 'Expo', 'Rock']}>
  <Tab value="Bare">

```ts title="hot-updater.config.ts"
import { existsSync } from "node:fs";
import { bare } from "@hot-updater/bare";
import { withBugsnag } from "@hot-updater/bugsnag-plugin"; // [!code ++]
import { defineConfig } from "hot-updater";

if (existsSync(".env.hotupdater")) {
  process.loadEnvFile(".env.hotupdater");
}

export default defineConfig({
  build: withBugsnag( // [!code ++]
    bare({
      enableHermes: false, // or true, depending if you want to use it
      // Required for sourcemap upload
      sourcemap: true, // [!code ++]
    }),
    { // [!code ++]
      // Your BugSnag project API key
      apiKey: process.env.BUGSNAG_API_KEY!, // [!code ++]
    }, // [!code ++]
  ), // [!code ++]
  // .. your other config
});
```
</Tab>

<Callout title="Automatic Upload">
`withBugsnag()` uploads all generated sourcemaps to BugSnag during `hot-updater deploy`. Each upload is identified by a `codeBundleId`, which defaults to the bundle id hot-updater generates for the deploy.
</Callout>

## Step 2: Set the `codeBundleId` in your app

BugSnag matches errors from OTA-updated apps to the uploaded sourcemaps through
the `codeBundleId`. Add the file identifier from the current manifest to your
existing `Bugsnag.start` options, retaining the rest of your configuration:

```tsx title="App.tsx"
import Bugsnag from "@bugsnag/react-native";
import { HotUpdater } from "@hot-updater/react-native"; // [!code ++]

Bugsnag.start({
  // Keep your existing BugSnag options.
  codeBundleId: HotUpdater.getManifest().bundleId, // [!code ++]
});
```

This keeps sourcemap matching tied to the running code, including when the
same files are promoted to another channel.

## Step 3: Deploy

Deploy the update to build the bundle and upload its sourcemaps to BugSnag.

```package-install
npx hot-updater deploy -i
```

## Verify symbolication

Install a release build, deploy a small JavaScript change with sourcemaps
enabled, and trigger a controlled test error from the updated code. In your
monitoring dashboard, confirm the stack points to the original source file
and line in that update. A successful upload alone does not prove the app and
uploaded map use the same identity.
