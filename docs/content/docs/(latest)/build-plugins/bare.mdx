---
title: "Bare (CLI) Plugin"
description: Build plugin for non-Expo projects that runs the project's configured bundler through the React Native CLI bundle command.
icon: react
---

## Installation

```package-install
npm install @hot-updater/bare --save-dev
```

## Configuration

```typescript
interface BarePluginConfig {
  outDir?: string;           // Output directory (default: "dist")
  entryFile?: string;        // Entry file (default: "index.js")
  sourcemap?: boolean;       // Generate sourcemaps (default: false)
  resetCache?: boolean;      // Reset Metro cache before bundling (default: true)
  enableHermes: boolean;     // Use Hermes compiler (required)
}
```

## Usage

```typescript title="hot-updater.config.ts"
import { bare } from '@hot-updater/bare'; // [!code ++]
import { defineConfig } from 'hot-updater';

export default defineConfig({
  build: bare({ // [!code ++]
    enableHermes: true, // [!code ++]
    sourcemap: false, // [!code ++]
    entryFile: 'index.js' // [!code ++]
  }), // [!code ++]
  // ... other config
});
```

## Key features

- Runs the project's configured bundler through the React Native CLI `bundle` command
- Automatic Hermes bytecode compilation when enabled
- Disables the bundler's minification when Hermes compilation is enabled
- Supports custom entry files and output directories
