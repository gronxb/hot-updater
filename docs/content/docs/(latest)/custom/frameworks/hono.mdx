## Installation

Install Hono.

```package-install
npm install hono
```

## Setup and Security

Set up a [database adapter](/docs/custom/database/drizzle), generate its Hot Updater
schema, and apply the schema before starting the server.

The recommended self-hosted client policy uses built-in API key authentication
for update-check and Insights ingestion routes. Always protect admin routes with
framework middleware before mounting the admin handler. Update-check
routes are usually exposed for React Native clients, but that is a deployment
choice:

- Client OTA: `/hot-updater/release-catalogs/*`, `/hot-updater/artifacts/*`
- Optional public diagnostics: `/hot-updater/version`
- Protected admin API: `/hot-updater/admin/*`

The handlers are separate by construction. Mounting `handlers.admin` opts the
server into the admin API; `handlers.client` never serves those routes. This
example requires a nonempty token before mounting the admin handler:

```typescript title="src/index.ts"
import { Hono } from "hono";
import { bearerAuth } from "hono/bearer-auth"; // [!code ++]
import { hotUpdater } from "./hotUpdater"; // [!code ++]

const app = new Hono();
const adminToken = process.env.HOT_UPDATER_ADMIN_TOKEN;

if (!adminToken) {
  throw new Error("HOT_UPDATER_ADMIN_TOKEN is required");
}

app.use( // [!code ++]
  "/hot-updater/admin/*", // [!code ++]
  bearerAuth({ token: adminToken }), // [!code ++]
); // [!code ++]

app.mount("/hot-updater/admin", hotUpdater.handlers.admin); // [!code ++]
app.mount("/hot-updater", hotUpdater.handlers.client); // [!code ++]

export default app;
```

Register the middleware first, then the specific admin mount, then the broader
client mount. To run a client-only server, omit the admin middleware and admin
mount entirely.

Set your auth token in environment variables:

```bash
HOT_UPDATER_ADMIN_TOKEN=your-secret-auth-token
```

Configure the CLI to include the auth token when deploying bundles:

```typescript title="hot-updater.config.ts (excerpt)"
import { standaloneRepository } from "@hot-updater/standalone"; // [!code ++]
import { defineConfig } from "hot-updater";

const adminToken = process.env.HOT_UPDATER_ADMIN_TOKEN;
if (!adminToken) {
  throw new Error("HOT_UPDATER_ADMIN_TOKEN is required");
}

export default defineConfig({
  // ...
  database: standaloneRepository({ // [!code ++]
    baseUrl: "http://localhost:3000/hot-updater/admin", // [!code ++]
    commonHeaders: { // [!code ++]
      Authorization: `Bearer ${adminToken}`, // [!code ++]
    }, // [!code ++]
  }), // [!code ++]
});
```

## Handler Boundaries

Insights ingestion and query capabilities are built in. Client reporting is on
by default and can be disabled in the mobile SDK. The client API key protects
catalog reads, artifact resolution and Insights ingestion; it does not
protect or authorize the admin handler.

See the [shared handler boundary](/docs/custom/overview#runtime-policy) for route
groups and the [repository server contract](/docs/database-plugins/standalone#server-contract)
for exact management requests. Keep the framework-specific authentication and
mount ordering shown above.

Before connecting the app, verify that `/hot-updater/version` responds and an
admin request without the expected token is rejected. Then use
[CLI configuration](/docs/custom/cli-configuration#verify-the-connection) to
verify authenticated management access.

## React Native Setup

[Create a client API key](/docs/custom/api-key-authentication#bootstrap-a-self-hosted-client)
against the prepared database, then follow [Set up your app](/docs/get-started/app-setup).
Use the client root as `baseURL` and send the key through `x-api-key`. Never
put the admin token in the app.

For local connectivity checks, `localhost` reaches the host from the iOS
Simulator on the same Mac and `10.0.2.2` does so from the Android Emulator.
Before a release-build OTA test, expose the server through a reachable HTTPS
endpoint and use it in the app; changing the host address does not enable
cleartext HTTP. Complete [Test an OTA update](/docs/get-started/test-ota)
against that HTTPS endpoint.
