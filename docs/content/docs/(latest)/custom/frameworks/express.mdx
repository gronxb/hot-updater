## Installation

Install Express and required dependencies.

```package-install
npm install express
npm install @types/express --save-dev
```

## Setup and Security

Set up a [database adapter](../database/drizzle), generate its Hot Updater
schema, and apply the schema before starting the server.

Built-in client access-key authentication is opt-in and protects only
update-check and Analytics ingestion routes. Always protect bundle management
routes with framework middleware before mounting the handler. Update-check
routes are usually exposed for React Native clients, but that is a deployment
choice:

- Client OTA: `/hot-updater/release-catalogs/*`, `/hot-updater/artifacts/*`
- Optional public diagnostics: `/hot-updater/version`
- Protected management API: `/hot-updater/api/*`

Management routes are disabled by default. Enable them only on a server where
framework authentication protects the entire management prefix:

```typescript title="src/hotUpdater.ts (route excerpt)"
export const hotUpdater = createHotUpdater({
  // Keep the database and storage fields from your adapter setup.
  features: {
    updateCheck: true,
    bundles: true,
  },
});
```

Require a nonempty token at startup, parse JSON before handing requests to the
Node bridge, and mount with `app.use`. This works with Express 5 and handles the
mount root as well as child paths:

```typescript
import { toNodeHandler } from "@hot-updater/server/node";
import express, {
  type NextFunction,
  type Request,
  type Response,
} from "express";
import { hotUpdater } from "./hotUpdater"; // [!code ++]

const authToken = process.env.HOT_UPDATER_AUTH_TOKEN;
if (!authToken) {
  throw new Error("HOT_UPDATER_AUTH_TOKEN is required");
}

const app = express();
const handler = toNodeHandler(hotUpdater); // [!code ++]

app.use(express.json());

const requireManagementToken = (
  req: Request,
  res: Response,
  next: NextFunction,
) => {
  if (req.get("Authorization") !== `Bearer ${authToken}`) {
    return res.status(401).json({ error: "Unauthorized" }); // [!code ++]
  }
  next(); // [!code ++]
}; // [!code ++]

app.use("/hot-updater/api", requireManagementToken); // [!code ++]
app.use("/hot-updater", handler); // [!code ++]

app.listen(3000);
```

Set your auth token in environment variables:

```bash
HOT_UPDATER_AUTH_TOKEN=your-secret-auth-token
```

Configure the CLI's standalone database plugin to send the same token. This is
a database-field excerpt; keep the build, storage, and update-strategy fields
from your existing config:

```typescript title="hot-updater.config.ts (database excerpt)"
import { standaloneRepository } from "@hot-updater/standalone";
import { defineConfig } from "hot-updater";

const authToken = process.env.HOT_UPDATER_AUTH_TOKEN;
if (!authToken) {
  throw new Error("HOT_UPDATER_AUTH_TOKEN is required");
}

export default defineConfig({
  // Keep your build, storage, and updateStrategy fields here.
  database: standaloneRepository({
    baseUrl: "http://localhost:3000/hot-updater",
    commonHeaders: {
      Authorization: `Bearer ${authToken}`,
    },
  }),
});
```

## API Endpoints

The server always mounts `/version`. Update-check routes require
`features.updateCheck`; every management route requires `features.bundles` and
the framework middleware shown above.

| Method             | Endpoint                                                                                        | Purpose                                |
| ------------------ | ----------------------------------------------------------------------------------------------- | -------------------------------------- |
| GET                | `/hot-updater/version`                                                                          | Read the server version                |
| GET                | `/hot-updater/release-catalogs/app-version/:authorityId/:platform/:channelKey/:appVersion`      | Resolve an app-version Release Catalog |
| GET                | `/hot-updater/release-catalogs/fingerprint/:authorityId/:platform/:channelKey/:fingerprintHash` | Resolve a fingerprint Release Catalog  |
| GET                | `/hot-updater/artifacts/:targetBundleId/from/:currentBundleId`                                  | Resolve a full or patch artifact       |
| GET                | `/hot-updater/api/releases`                                                                     | List Releases                          |
| GET, PATCH, DELETE | `/hot-updater/api/releases/:id`                                                                 | Read, update, or delete a Release      |
| POST               | `/hot-updater/api/releases/:id/preflight`                                                       | Validate a Release change              |
| GET                | `/hot-updater/api/release-catalogs`                                                             | List Release Catalog rows              |
| GET                | `/hot-updater/api/release-catalogs/:scopeKey`                                                   | Read one Release Catalog row           |
| POST               | `/hot-updater/api/release-catalogs/:scopeKey/rebuild`                                           | Rebuild one Release Catalog            |
| POST               | `/hot-updater/api/database/commit`                                                              | Commit standalone database changes     |
| GET, POST          | `/hot-updater/api/channels`                                                                     | List or create Channels                |
| DELETE             | `/hot-updater/api/channels/:id`                                                                 | Delete an unreferenced Channel         |
| GET, POST          | `/hot-updater/api/bundles`                                                                      | List or create Bundles                 |
| GET, PATCH, DELETE | `/hot-updater/api/bundles/:id`                                                                  | Read, update, or delete a Bundle       |

## React Native Setup

Configure your React Native app to connect to this server.

```typescript title="App.tsx"
import { HotUpdater } from '@hot-updater/react-native';

export default HotUpdater.wrap({
  baseURL: 'http://localhost:3000/hot-updater', // [!code ++]
  updateStrategy: 'appVersion', // or "fingerprint" // [!code ++]
  fallbackComponent: ({ progress, status }) => (
    // ... Custom loading UI
  ),
  onError: error => {
    // ... Error handling
  },
})(App);
```
