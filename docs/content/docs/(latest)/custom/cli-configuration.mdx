## Overview

Your CLI configuration (`hot-updater.config.ts`) connects your React Native project to your self-hosted Hot Updater server. This file defines how bundles are built, stored, and tracked.

## Basic Configuration

Install the CLI dependencies in your React Native project:

```package-install
npm install --save-dev @hot-updater/bare @hot-updater/aws @hot-updater/standalone hot-updater dotenv
```

Create `.env.hotupdater` in that project with the server's `R2_*` storage values
and `HOT_UPDATER_ADMIN_TOKEN`, and add it to `.gitignore`. Then create
`hot-updater.config.ts` in the same project root:

```typescript title="hot-updater.config.ts"
import { bare } from "@hot-updater/bare";
import { s3Storage } from "@hot-updater/aws";
import { standaloneRepository } from "@hot-updater/standalone";
import { defineConfig } from "hot-updater";
import { config } from "dotenv";

config({ path: ".env.hotupdater" });

const adminToken = process.env.HOT_UPDATER_ADMIN_TOKEN;
if (!adminToken) {
  throw new Error("HOT_UPDATER_ADMIN_TOKEN is required");
}

export default defineConfig({
  build: bare({ enableHermes: true }),
  storage: s3Storage({
    region: "auto",
    endpoint: process.env.R2_ENDPOINT,
    credentials: {
      accessKeyId: process.env.R2_ACCESS_KEY_ID!,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
    },
    bucketName: process.env.R2_BUCKET_NAME!,
  }),
  database: standaloneRepository({
    baseUrl: "http://localhost:3000/hot-updater/admin",
    commonHeaders: {
      Authorization: `Bearer ${adminToken}`,
    },
  }),
  updateStrategy: "appVersion",
});
```

<Callout type="warn">
**Critical: Storage Plugin Must Match**

The CLI `storage` plugin must match one entry in the server's
`createHotUpdater({ storage })` array.

**CLI uses `s3Storage` → Server must use `s3Storage`**

Both sides need the same plugin type and URI configuration to encode and decode
the hierarchical `protocol://bucket/encoded/slash/key` storage URIs correctly.

</Callout>

## Standalone Repository Configuration

The `standaloneRepository` HTTP repository connects your CLI to your
self-hosted server:

```typescript
interface StandaloneRepositoryConfig {
  baseUrl: string; // Exact root where handlers.admin is mounted
  commonHeaders?: Record<string, string>; // Framework authentication headers
  routes?: Routes; // Optional legacy Bundle-route mapping
}
```

`routes` can remap only the five Bundle create, update, list, retrieve, and
delete requests. Release, Release Catalog, database commit, and Channel
requests use the fixed canonical paths summarized below.

### Secure Example

```typescript
const adminToken = process.env.HOT_UPDATER_ADMIN_TOKEN;
if (!adminToken) {
  throw new Error("HOT_UPDATER_ADMIN_TOKEN is required");
}

database: standaloneRepository({
  baseUrl: "http://localhost:3000/hot-updater/admin",
  commonHeaders: {
    Authorization: `Bearer ${adminToken}`,
  },
});
```

The admin handler does not authenticate requests itself. Keep its credential in
server-side CLI or Console configuration and match the framework middleware in
the server setup.

### Alternate Authentication

```typescript
database: standaloneRepository({
  baseUrl: process.env.HOT_UPDATER_ADMIN_URL!,
  commonHeaders: {
    "X-Internal-Service-Key": process.env.INTERNAL_SERVICE_KEY!,
  },
});
```

### With Custom Routes

```typescript
const adminToken = process.env.HOT_UPDATER_ADMIN_TOKEN;
if (!adminToken) {
  throw new Error("HOT_UPDATER_ADMIN_TOKEN is required");
}

database: standaloneRepository({
  baseUrl: "https://api.example.com/hot-updater/admin",
  commonHeaders: {
    Authorization: `Bearer ${adminToken}`,
  },
  routes: {
    create: () => ({
      path: "/v1/bundles",
      headers: { "X-Custom-Header": "value" },
    }),
    update: (bundleId) => ({
      path: `/v1/bundles/${bundleId}`,
      headers: { "X-Custom-Header": "value" },
    }),
    list: () => ({
      path: "/v1/bundles",
    }),
    retrieve: (bundleId) => ({
      path: `/v1/bundles/${bundleId}`,
    }),
    delete: (bundleId) => ({
      path: `/v1/bundles/${bundleId}`,
    }),
  },
});
```

## API Endpoints

Mounting `hotUpdater.handlers.admin` exposes the admin contract used by
`standaloneRepository`:

| Method | Default endpoint                              | Mapping    | Purpose                              |
| ------ | --------------------------------------------- | ---------- | ------------------------------------ |
| POST   | `/hot-updater/admin/bundles`                    | remappable | Create Bundles                       |
| PATCH  | `/hot-updater/admin/bundles/:id`                | remappable | Update a Bundle                      |
| GET    | `/hot-updater/admin/bundles`                    | remappable | List Bundles                         |
| GET    | `/hot-updater/admin/bundles/:id`                | remappable | Retrieve a Bundle                    |
| DELETE | `/hot-updater/admin/bundles/:id`                | remappable | Delete a Bundle                      |
| GET    | `/hot-updater/admin/releases/:id`               | fixed      | Retrieve a Release                   |
| GET    | `/hot-updater/admin/releases`                   | fixed      | List Releases                        |
| GET    | `/hot-updater/admin/release-catalogs/:scopeKey` | fixed      | Retrieve a Release Catalog row       |
| GET    | `/hot-updater/admin/release-catalogs`           | fixed      | List Release Catalog rows            |
| POST   | `/hot-updater/admin/database/commit`            | fixed      | Commit database mutations atomically |
| GET    | `/hot-updater/admin/channels`                   | fixed      | List Channels                        |
| POST   | `/hot-updater/admin/channels`                   | fixed      | Insert or resolve a Channel          |
| DELETE | `/hot-updater/admin/channels/:id`               | fixed      | Delete an unreferenced Channel       |

A Channel referenced by a Release is not empty and cannot be deleted. For the
complete request and response contract, use the canonical
[Standalone Repository server contract](/docs/database-plugins/standalone#server-contract).
The admin routes do not authenticate themselves; protect
`/hot-updater/admin/*` before mounting `handlers.admin`.
