## Before you start

Use this recipe in the server project from the [custom-server quick start](/docs/custom/quick-start)
or your existing backend. Make the database and storage environment variables
available to the server and schema commands. The React Native project's deploy
configuration is a separate step.

Run MongoDB as a replica set or sharded cluster and set `transactions: true`.
Release and Release Catalog changes must commit atomically. With transactions
disabled, commits with revision expectations or multiple changes are rejected,
so a standalone MongoDB server cannot support the normal deployment workflow.

## Installation

Install the MongoDB native driver.

```package-install
npm install @hot-updater/server @hot-updater/aws mongodb
```

```package-install
npm install --save-dev hot-updater
```

## Setup

Create a database connection file:

```typescript title="src/mongodb.ts"
import { MongoClient } from "mongodb";

export const client = new MongoClient(process.env.MONGODB_URI!);

// Connect to MongoDB
await client.connect();
```

## Hot Updater Configuration

Create the Hot Updater instance:

```typescript title="src/hotUpdater.ts"
import { createHotUpdater } from "@hot-updater/server";
import { mongoAdapter } from "@hot-updater/server/adapters/mongodb";
import { s3Storage } from "@hot-updater/aws";
import { client } from "./mongodb";

export const hotUpdater = createHotUpdater({
  database: mongoAdapter({ client, transactions: true }),
  clientAccess: { type: "api-key" },
  storage: [
    s3Storage({
      region: "auto",
      endpoint: process.env.R2_ENDPOINT,
      credentials: {
        accessKeyId: process.env.R2_ACCESS_KEY_ID!,
        secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
      },
      bucketName: process.env.R2_BUCKET_NAME!,
      downloadUrlSigningKey: process.env.HOT_UPDATER_STORAGE_DOWNLOAD_URL_KEY!,
    }),
  ],
});
```

## Schema Generation

Run the database migration to create the MongoDB collection and indexes.

```bash
npx hot-updater db migrate src/hotUpdater.ts
```

This command targets `src/hotUpdater.ts` and creates all Hot Updater
collections and indexes required by the active database schema.

## CLI Configuration

After the schema is applied, [create the client API key](/docs/custom/api-key-authentication#bootstrap-a-self-hosted-client)
using this same direct server configuration. Then
[connect the React Native project's CLI](/docs/custom/cli-configuration) to the
protected admin mount. Its storage configuration must match a server entry.

## API Endpoints

The adapter persists data; your framework mounts the HTTP handlers. Continue
with the [Hono](/docs/custom/frameworks/hono), [Express](/docs/custom/frameworks/express)
or [Elysia](/docs/custom/frameworks/elysia) recipe. See the
[handler boundaries](/docs/custom/overview#runtime-policy) and
[repository contract](/docs/database-plugins/standalone#server-contract) for
client and admin access.

Finish with [Set up your app](/docs/get-started/app-setup) and
[Test an OTA update](/docs/get-started/test-ota).
