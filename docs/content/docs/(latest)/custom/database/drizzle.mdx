## Installation

Install Drizzle ORM and SQLite driver.

```package-install
npm install drizzle-orm better-sqlite3 @types/better-sqlite3 --save-dev
```

For other databases, see [Drizzle's adapter documentation](https://orm.drizzle.team/docs/get-started).

## Setup

Create a database connection file:

```typescript title="src/drizzle.ts"
import { drizzle } from "drizzle-orm/better-sqlite3";
import Database from "better-sqlite3";

const sqlite = new Database("./data/database.db");
export const db = drizzle(sqlite);
```

## Hot Updater Configuration

Create the Hot Updater instance:

```typescript title="src/hotUpdater.ts"
import { createHotUpdater } from "@hot-updater/server";
import { drizzleAdapter } from "@hot-updater/server/adapters/drizzle";
import { r2Storage } from "@hot-updater/cloudflare";
import { db } from "./drizzle";

export const hotUpdater = createHotUpdater({
  database: drizzleAdapter({ db, provider: "sqlite" }),
  storage: [
    r2Storage({
      accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
      credentials: {
        accessKeyId: process.env.R2_ACCESS_KEY_ID!,
        secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
      },
      bucketName: process.env.R2_BUCKET_NAME!,
      downloadUrlSigningKey: process.env.HOT_UPDATER_STORAGE_DOWNLOAD_URL_KEY!,
    }),
  ],
  basePath: "/hot-updater",
});
```

## Schema Generation

Generate the Drizzle schema for Hot Updater tables.

```bash
npx hot-updater db generate src/hotUpdater.ts --yes
```

This command targets the `src/hotUpdater.ts` file and adds the necessary table definitions.

<Callout>
  Need to generate SQL without config? See [SQL
  Export](/docs/custom/database/sql-export) for standalone SQL generation with
  the `--sql` flag.
</Callout>

## CLI Configuration

Configure your CLI to use this self-hosted server.

```typescript title="hot-updater.config.ts"
import { defineConfig } from "@hot-updater/core";
import { bare } from "@hot-updater/bare";
import { r2Storage } from "@hot-updater/cloudflare";
import { standaloneRepository } from "@hot-updater/standalone";

export default defineConfig({
  build: bare(),
  storage: r2Storage({
    accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
    credentials: {
      accessKeyId: process.env.R2_ACCESS_KEY_ID!,
      secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
    },
    bucketName: process.env.R2_BUCKET_NAME!,
  }),
  database: standaloneRepository({
    baseUrl: "http://localhost:3000/hot-updater",
  }),
});
```

<Callout type="warn">
  The CLI `storage` plugin must match a plugin in your server's
  `createHotUpdater({storage})` array. Both use `r2Storage` in this example.
</Callout>

## API Endpoints

The server automatically creates these endpoints:

| Method | Endpoint                                                                              | Description                                                         |
| ------ | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| GET    | `/hot-updater/version`                                                                | Get server version                                                  |
| GET    | `/hot-updater/release-catalogs/:strategy/:authorityId/:platform/:channelKey/:value` | Fetch a Release Catalog |
| GET    | `/hot-updater/artifacts/:targetBundleId/from/:currentBundleId` | Resolve an artifact |
| GET    | `/hot-updater/api/bundles`                                                            | List bundles (query: channel, platform, limit, page, after, before) |
| GET    | `/hot-updater/api/bundles/:id`                                                        | Get bundle by ID                                                    |
| POST   | `/hot-updater/api/bundles`                                                            | Create bundles                                                      |
| PATCH  | `/hot-updater/api/bundles/:id`                                                        | Update a bundle                                                     |
| DELETE | `/hot-updater/api/bundles/:id`                                                        | Delete bundle                                                       |
| GET    | `/hot-updater/api/channels`                                                           | List all channels                                                   |
| POST   | `/hot-updater/api/channels`                                                           | Insert or resolve a channel                                         |
| DELETE | `/hot-updater/api/channels/:id`                                                       | Delete an empty channel                                             |
