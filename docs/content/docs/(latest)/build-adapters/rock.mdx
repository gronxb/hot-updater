## Installation

```package-install
npm install @hot-updater/rock --save-dev
```

## Configuration

```typescript
interface RockAdapterConfig {
  outDir?: string;      // Output directory (default: "dist")
  entryFile?: string;   // Entry file (default: "index.js")
  sourcemap?: boolean;  // Generate sourcemaps (default: false)
  hermes?: boolean;     // Use Hermes compiler (default: true)
}
```

## Usage

```typescript title="hot-updater.config.ts (excerpt)"
import { rock } from '@hot-updater/rock'; // [!code ++]
import { defineConfig } from 'hot-updater';

export default defineConfig({
  build: rock({ // [!code ++]
    hermes: true, // [!code ++]
    entryFile: 'index.js', // [!code ++]
    sourcemap: false // [!code ++]
  }), // [!code ++]
  // ... storage, database, plugins, and updateStrategy
});
```

## Key features

- Build adapter for [Rock framework](https://www.rockjs.dev/)
- Supports Hermes compilation
- Configurable output directory and entry files
