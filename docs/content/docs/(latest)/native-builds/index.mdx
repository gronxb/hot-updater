## Why native builds are tracked

`hot-updater native-build ios` and `native-build android` build the native
app from a scheme in `hot-updater.config.ts` and record the build with your
server. A tracked build is three things at once:

- **An OTA patch base.** The JavaScript bundle built into the app is kept, so
  a fresh install's first OTA downloads a small patch instead of the complete
  bundle. See [Bundle Diffing](/docs/guides/bundle-diffing#first-ota-update).
- **A preview build.** The Console lists each build with an install link, and
  [pull request previews](/docs/guides/pull-request-previews) find the build a
  pull request's update runs on.
- **A store upload.** `testflight` and `google-play upload` build, track, and
  upload in one command, and the Console shows which builds are on a store.

A build made elsewhere can be tracked too, by
[importing it](/docs/guides/native-build#import-a-build-made-elsewhere).
