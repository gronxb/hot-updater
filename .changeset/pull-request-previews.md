Pull requests get previews from a GitHub Action, `gronxb/hot-updater/actions/preview`, which reads its credentials through the config's `secrets` adapter, the job's environment by default. For each platform it deploys the pull request's bundle to the pull request's own channel (`pr-<number>`), and builds a preview native build, which Hot Updater tracks, on the shared preview channel only when the registry has none for the project's fingerprint, or app version. It keeps one comment on the pull request, edited on every push: each platform's download and page links in the Console's Native builds tab, whether the run built or reused the native build, the bundle, and the QR code of the channel link, with a "Preview by hot-updater" line that `credit: false` turns off. When the runner can't reach the Console, such as a private one on a VPN, or the Console serves no channel link, the comment shows the link from the project's own `console.channelLinkPrefix`, with its `adb` and `xcrun simctl openurl` commands and without the QR code, and the job's log says which of the two happened. When the pull request closes, it deletes the channel and its bundles. iOS previews a Simulator app on a macOS runner. When a native build fails, the action uploads the CLI's build log as the `hot-updater-preview-build-log-<platform>` artifact.

- `hot-updater native-build find -p <platform> [-c <channel>] [-s <scheme>] [--json]` prints the newest tracked native build that a build of the project would match: the fingerprint from the config's fingerprint inputs, or with the `appVersion` strategy, the version of the app the scheme builds, on the native project's default channel or `--channel`. With `--scheme`, the build must be the kind of artifact the scheme builds. No build prints `nativeBuild: null` and succeeds.
- `hot-updater channel link <channel> [--json]` prints a channel's link, which `console.channelLinkPrefix` in `hot-updater.config.ts` makes as the Console does, with the `adb` and `xcrun simctl openurl` commands that open it. `--json` prints `{ channel, link }`, with a null `link` when the config sets no prefix.
- `hot-updater native-build ios|android --json` prints `{ dryRun, build, nativeBuild, registration, submission }` as the last line of its output: the build, with the channel and the fingerprint or app version its artifact embeds, its record (null for a Debug build or a dry run, with `registration.skipped` saying why), and the store it went to.
- The Console serves `/_hot-updater/preview/channel-qr?channel=<channel>`, the QR code of the channel's link as an SVG image, without a session, so a pull request comment can show it. It holds only the link `console.channelLinkPrefix` and the channel make, reads nothing else, and answers 404 without a prefix.
