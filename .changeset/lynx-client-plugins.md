Support framework-neutral client plugins with native installation identity and persistent storage excluded from backups. Report primary readiness, update checks, verified staging transport, failures, and HTTP responses without awaiting observer hooks.

Return a fresh configured instance from `HotUpdater.init`, exposing each plugin's API immediately. Keep request settings and hooks independent across instances and read current native state through context-bound getters. Resolve functional server URLs only when requests start, preserving offline readiness in scaffold pages.
