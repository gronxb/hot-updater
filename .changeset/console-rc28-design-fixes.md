Console design fixes from the rc.28 review. On an iPhone, Apple's refusal and a check that couldn't start show as the install card's error with one next step, and the computer's install options sit under "Other ways to install". The iOS devices page marks Apple's refusal with an "Apple refused" badge, names CLI-added devices "Added from a terminal", and shortens the Remove dialog. Native builds show "Older" beside the kind, as Bundles shows "Unreachable", and both tables shade folded rows lighter so channel badges meet AA contrast. The IPA device list shows an unnamed device as "Unknown device" over its masked UDID, with the full UDID copyable. A fold that fails names its rows, every spinner respects reduced motion, and empty values use one glyph.
