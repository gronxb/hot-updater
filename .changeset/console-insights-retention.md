**Delete data** on an installation's history deletes that installation's Insights data, or that of every installation of its user, after a confirmation. The console offers it when the server runs `insights()`, including through `standaloneRepository`. App usage adds a **12m** period, **YAU**, that counts 52 weeks of whole UTC days from the daily totals. The console reads how long the server keeps Insights data, from a self-hosted server's admin API too, with the defaults for a server that does not report it: event lists offer ranges within the raw period, **12m** shows where daily totals cover it, and event lists, installation history, and App usage say how long data is kept.
