On an iPhone, the iOS devices page now shows this iPhone's registry state (requested, approved, registered, or Apple's refusal) once its profile has answered, in place of the Install profile form. This holds after a reload, in a new tab, and when Safari returns to the tab already open. An approver can approve it from the card. The page also scrolls on a phone again: the device list no longer shrinks to the height left under the Register card and gets cut off.
