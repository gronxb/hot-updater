The build's page on an iPhone offers **Install profile** until the iPhone has sent its UDID, then **Install**. The profile is named "Hot Updater Device Profile", and after it installs, Safari goes straight back to the build's page. "Install anyway" is gone: an iPhone the IPA doesn't list gets the command for a maintainer.
