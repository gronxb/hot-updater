The Native builds tab's "Import a build" dialog is a title, one line ("Track an .ipa, .aab, .apk or .app built elsewhere as a patch base."), the command `npx hot-updater native-build import <file>` with its copy button, and the Import guide link. The empty state shows the same shorter command. The rest, such as `--channel`, is in the guide.
